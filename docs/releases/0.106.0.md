# DolphinClient 0.106.0 — A new look, and accounts

Target: the dolphinclient.de website and its deployment. This release does
not touch the client or launcher.

## Changes

- The whole website — home, features, download, changelog and the admin
  portal — moved to a new design system shared with the AFKSystems panel's
  visual language: light by default with a dark override, a blue primary
  color with a violet second color for labels, Host Grotesk throughout, and
  rings (`box-shadow: inset 0 0 0 1px`) instead of borders on every card and
  control. The token values changed; the CSS variable names did not, so the
  whole site re-themes from one block in `globals.css`.
- New: email/password accounts, backed by a new `account-api.mjs` service
  with its own SQLite database. Passwords are scrypt-hashed; sessions are a
  random token whose HMAC digest is stored, never the token itself, in an
  HttpOnly/SameSite=Lax cookie with a 30-day expiry.
- New pages: `/register`, `/login`, `/forgot`, `/reset` and a protected
  `/dashboard` that redirects to `/login` when signed out.
- The dashboard: account details with in-place display-name and password
  changes and account deletion; a Minecraft profile card that validates a
  username against the Mojang API and shows a live skin preview; current
  downloads by platform (reusing the published manifest); the newest
  changelog entries; and session controls, including signing out of every
  session at once.
- Password-reset email is implemented end to end (nodemailer, one-hour
  single-use tokens that invalidate every session on use) but is off by
  default — `/auth/forgot` says so plainly — until SMTP is configured in
  `/etc/dolphinclient/account.env` on the server.
- Per-IP rate limiting on `/auth/register` and `/auth/login` (in-process, no
  new dependency) and a self-test (`deploy/test-account-api.mjs`) exercising
  the golden path and every rejection.
- Deployment: `deploy/setup-account-api.sh` installs the service (systemd,
  `DynamicUser`, its own state directory) and the nginx snippet that proxies
  `/account-api/` — deliberately with **no** Cloudflare Access gate, since
  registration is public by design; the admin portal's gate is unchanged.
  `deploy/README.md` documents both backend services; two stale lines that
  claimed `redeploy.sh` touches a backend were corrected — it only ever
  rebuilds the static export.
- Cleanup: the critical Next.js advisory and the nodemailer SMTP-injection
  advisory (freshly introduced by this release) are both patched; no
  orphaned website components or leftover files from the earlier "Sonar"
  design were found.

## Reference

The design values (colors, radii, font) were copied from the live
AFKSystems panel at `/home/benj/AFKSystems` (`public/assets/css/app.css`),
which the user pointed to as the reference. The account API's session and
password-hashing scheme follows the same panel's `server/auth.js` and
`server/util.js` in spirit — scrypt, an HMAC-digested opaque session token —
reimplemented locally rather than shared as code, since the two backends are
unrelated projects.
